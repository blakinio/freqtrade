# Granice licencyjne i clean-room

## LuxAlgo

Dostarczony kod Smart Money Concepts zawiera nagłówek `CC BY-NC-SA 4.0`.

Zasady projektu:

- nie kopiować kodu LuxAlgo do komercyjnego repo,
- nie portować linia po linii,
- nie zachowywać identycznej struktury funkcji i nazw,
- nie używać kodu jako zależności produkcyjnej,
- do publicznego lub komercyjnego wykorzystania uzyskać ocenę prawną lub zgodę właściciela.

Dozwolony kierunek techniczny:

- opisać niezależnie pojęcie,
- przygotować własną specyfikację,
- wdrożyć clean-room,
- dokumentować provenance,
- utrzymywać testy własnej semantyki.

## Miyagi

Brak pełnego kodu oznacza:

- brak możliwości potwierdzenia wzorów,
- brak możliwości potwierdzenia repaintingu,
- brak zgodności parity,
- zakaz traktowania jako ground truth.

Może służyć jako źródło hipotez i benchmark UI.
