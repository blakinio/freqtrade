# Visual asset gallery

Repository-safe WebP assets are committed directly under `assets/`. Run `python docs/ai_platform/quant_platform_v2/gui/restore_visual_assets.py --extract /tmp/quant-v2-assets` from a checkout to reproduce the deterministic ZIP. Exact member names, file hashes and archive integrity data are in `ASSET_MANIFEST.json`.

> Privacy note: WickHunter reference members are privacy-redacted repository copies. Source originals are not part of the restore path and are not committed.
